與**時效**（「2025年11月最新」）。

〔推論〕身分宣告不是未具名權威的變體，它是另一種東西：
未具名權威至少指向某個外部來源（「國際共識」），而身分宣告指向的是**產生這段文字的模型
被要求扮演的角色**。它讀起來像出處，卻連宣稱有出處都沒有——它宣稱的是作者資格。

**七次對應的正是七段問答，每段開場各一次**。體質診斷仍成立，但機制是接縫，不是語氣。

## 5. 初稿的錯誤：把時效限定當成裝飾（16 處）

這是本單最重要的一節。

### 5.1 錯在哪

`source-editing.md` §3.1 的可刪類是「純評價性時間形容詞」，條件之一是「刪除後語意不變」。
初稿把 38 個 `adj` 命中全部視為滿足此條件。逐句核對後發現有一類根本不滿足：

```
改前：目前沒有任何 heparanase 特異性抑制劑獲得核准上市
改後：沒有任何 heparanase 特異性抑制劑獲得核准上市      ← 變成無時效的絕對斷言
```

```
改前：SGLT2i 是目前臨床已證實最強的間接 heparanase 抑制劑
改後：SGLT2i 是臨床已證實最強的間接 heparanase 抑制劑    ← 變成無時效的最高級
```

這裡的「目前」不是修飾語，是**斷言的有效範圍**。刪掉之後句子從
「截至某時點為止如此」變成「本來就如此」——**比留著更錯**。

### 5.2 為什麼會弄錯

因為它與可刪類長得一模一樣。同一個「目前」，在 L95
（「也是目前『保護內皮糖萼』成為新治療標的的原因」）是純修飾，
在 L563 是斷言範圍。詞表分不出來，只有讀句子才分得出來。

判準：**刪掉之後，這句話是否宣稱了比原本更多的東西？**
- 更多 → 時效限定，不刪
- 一樣 → 純修飾，可刪

〔推論〕這與 STATUS §3.14「範圍被整段往上平移」是同構的——那條記的是
數值範圍的兩端被錯置，這裡是斷言的**時間範圍**被整個移除。
兩者都不是把某個東西寫錯，而是把某個東西的**邊界**弄丟了。
邊界丟失比數值錯誤更難察覺，因為剩下的每個字都還是對的。

〔推論〕還有一層反諷：措辭政策的出發點是「時間形容詞會隨時間自動變成偽陳述」。
但在這 16 處上，**刪掉時間形容詞才會讓句子立刻變成偽陳述**。
同一個詞，在裝飾位置上是將來的錯，在限定位置上是現在的正確。

### 5.3 連帶：`v3` 執行單有一處要改判

`2026-07-30-source-v3-wording.md` §2 把 L77 列為可刪：

```
改前：已成為當前的標準方法
改後：已成為標準方法          ← 同型錯誤，變成無時效的斷言
```

**應改判為不刪，理由歸入 §3.2 型。** `v3` 的可刪處數由 8 降為 7。

該檔屬「待核准提案」，依 STATUS §3.8 為必改類（核准後會照著執行），
故直接修正，不另寫更正單。其餘 7 處經同一判準複核，維持可刪。

### 5.4 建議補進 `source-editing.md`

> §3.1 的條件二「刪除後語意不變」須以下列方式檢驗：
> 刪除後這句話是否宣稱了比原本更多的東西？是則該形容詞為**斷言的時效限定**，
> 不得刪除，記入清單。常見形式：現況陳述（「目前沒有／目前唯一」）、
> 最高級（「目前最強／目前證據最強」）、階段陳述（「目前進入人體二期」）。

| 案例 | 標題裡的措辭 | 該怎麼做 |

| `v3` L288「4.3 **新興**致病因子」 | 界定該節收哪些因子 | **分節依據**，保留 |
| `heparanase` L574「6.7 **2025年11月**臨床試驗現況總結」 | 界定快照的時點 | **分節依據**，保留 |

**建議補進 `source-editing.md` §3**：

> 標題中的時間或權威措辭，先判斷它是**裝飾註記**還是**分節依據**。
> 測試方式：刪除後，該標題是否仍然只指涉原本那一節、且不指涉更多內容？
> 是則為裝飾，整體刪除；否則為分節依據，保留並記入清單。

這一條同時解掉 `v3` 執行單 §3.2 記的缺口與本檔的兩個案例。

〔推論〕與 §5.4 的判準是同一個測試的兩種寫法——都是問「刪掉之後它指涉的範圍是否變大」。
標題上範圍變大表現為指涉更多節，句子上表現為宣稱更多事。建議兩條並列寫進 §3.1，
共用同一個測試句。
