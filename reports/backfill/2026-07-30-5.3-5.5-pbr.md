# 回填批次：`5.3` 與 `5.5` 的 PBR 群

```
執行日期: 2026-07-30
條數: 2
判定: unsupported 1 / partial 1
檢索紀錄: inbox/2026-07-30-5.3-5.5-pbr.json
```

本批的目的除了判定，還在**驗證 STATUS §3.3「逆向指標被寫反」的通則**——
`2.1.1-consensus-2-4um` 判 `unsupported` 的原因正是 PBR 被誤讀為厚度，
而這兩條直接談 PBR。結果是通則沒有再次命中，但兩條各自暴露了別的問題。

---

## 1. `5.3-pbr-precedes-cognitive-2-3y` → `unsupported`

**statement**：糖萼生物標記異常先於認知功能衰退 2-3 年出現。

### 1.1 檢索範圍

四次不同措辭，涵蓋三種切入角度：

| 角度 | 結果 |
|---|---|
| PBR ＋ 縱向 ＋ 認知衰退 | 無對位命中 |
| 糖萼生物標記 ＋ 失智 ＋ 前導時間 | 命中一篇**非糖萼**的研究，見 §1.2 |
| 精確字串「2-3 years」＋ glycocalyx | 未命中 |

檢索到的 PBR 縱向研究確實存在，但終點全部不是認知功能：
慢性心衰二年追蹤以死亡率為終點（PBR 1.9 μm 為最佳切點，AUC 0.77）、
另有以心血管事件為終點者。**沒有任何一篇以認知衰退為終點。**

腦血管糖萼的活體量測也存在（顳葉癲癇手術中皮質 PBR 2.64 ± 0.52 vs 對照 1.31 ± 0.29 μm），
但那是橫斷面、單次量測，不含時序。

### 1.2 漂移來源候選：`PMID:39494362`

〔文獻〕Brain Communications，Karolinska GEDOC 世代，n = 251，平均追蹤 10.7 ± 4.1 年。
CSF bisecting GlcNAc 高者認知衰退提前：類澱粉陰性組 β = 2.53 ± 0.85 年（P = 0.003）、
tau 陰性組 β = 2.43 ± 1.01 年（P = 0.017）。

量級與「2-3 年」相符，時序方向也相符（標記先於衰退）。但有**三處不對位**：

| | 原 statement | `PMID:39494362` |
|---|---|---|
| 標的 | 糖萼（內皮表面結構） | 腦脊髓液中的 N-醣鏈結構（bisecting GlcNAc） |
| 量測法 | 隱含 PBR／SDF（原文括號註明「如 PBR 升高」） | 酵素連結凝集素分析（ELLA） |
| 那個數字是什麼 | 標記異常領先終點的**前導時間** | MMSE **軌跡的整體提前量**（迴歸係數 β） |

第三點最關鍵：β 是「高標記組的認知軌跡比低標記組提前約 2.5 年」，
不是「標記在衰退前 2.5 年就已異常」。兩者在時間軸上指的不是同一段距離。

### 1.3 新的模式：譯名相近的相鄰概念被互換

〔推論〕如果 `PMID:39494362`（或同一研究線的其他論文）確實是來源，
那麼漂移發生在**概念名稱**這一層，而且中文放大了它：

```
glycan biomarker      醣類生物標記
glycocalyx biomarker  糖萼生物標記
```

英文的 `glycan` 與 `glycocalyx` 已經共用詞根，中文的「醣／糖」更是同音同源。
一個關於醣鏈的發現，被轉述成關於糖萼的發現，字面上只差一個詞。

這與 §3.12「歸屬漂移發生在分子層」同族但更外層：
§3.12 是同一領域內把功能或數值歸給錯的分子（電荷選擇性歸給 HS 而非唾液酸），
本例是**跨到相鄰領域**——糖生物學與血管生物學各有一套「醣」的研究，
兩者的標記完全不同，但在中文轉述裡難以分辨。

〔推論〕這一型的檢出成本特別高。查證「糖萼標記能否預測認知衰退」時，
檢索式裡放 `glycocalyx` 永遠查不到那篇論文——它根本不在那個檢索空間裡。
必須先懷疑「這個詞是不是被換過」，才會去查另一個詞。

### 1.4 `evidence` 留空的理由

同 §3.13 與 §5「觀察中」記錄的問題：`PMID:39494362` 既不支持也不反駁本主張。
它量的是別的分子、用別的方法、給的是別的量。寫進 `evidence` 會讓它看起來
與本主張有支持或反駁關係，兩者都不成立。故只寫入 `note`。

**這是同型的第五筆。** 前四筆見 STATUS §5「觀察中」。

## 2. `5.5-pbr-sdc1-correlation` → `partial`

**statement**：PBR 升高與血漿 Syndecan-1 升高通常呈正相關。

### 2.1 方向成立，強度與「通常」都不成立

| 出處 | 族群 | 結果 |
|---|---|---|
| `PMID:29462714` | 非敗血症加護病人（神經重症、心臟術後） | syndecan-1 與舌下 PBR **弱**相關 |
| `PMID:36523784` | CABG 體外循環，n = 23 | PBR 與 syndecan-1 **弱**相關；與 heparan sulfate、E-selectin、thrombomodulin **中度**相關 |
| ISICEM 增刊敗血症摘要，n = 31 | 敗血症入 ICU | syndecan-1 與 APACHE II（ρ = 0.60）、Ang-2/Ang-1（ρ = 0.59）相關，**與 PBR 不相關** |

三筆裡兩筆弱正相關、一筆無相關。方向沒錯，但「通常呈正相關」把弱相關講成了常規關係。

`PMID:36523784` 的結論寫得很直接：各標記之間的相關性有限，**沒有任何單一標記
能代表糖萼的全貌**。而 PBR 與 syndecan-1 恰好是該研究中相關性最弱的組合之一。

### 2.2 `r = 0.40` 只存在於會議摘要

值得單獨記一筆：`PMID:29462714` 的同儕審查全文只寫「weak correlation」，
**沒有給係數**。`r = 0.40（p = 0.002）` 這個數值出現在同一研究群的
ISICEM 會議摘要（`DOI:10.1186/s13054-018-1973-5`）。

〔推論〕這與 §3.2「敏感度／特異度整欄查無出處」是鏡像關係：
那邊是數字查無出處，這邊是數字有出處但出處的等級低於它看起來的樣子。
引用時若只寫「r = 0.40」而不註明來自會議摘要，讀者會以為它來自那篇全文。

### 2.3 原 note 的假設不成立

原 `note` 寫「若成立則兩者可互為驗證」。查證後這個假設本身有問題：

〔推論〕PBR 與 syndecan-1 量的不是同一個東西。
PBR 是**當下**的屏障通透性（紅血球能滲入多深），syndecan-1 是**累積**的脫落產物
在血中的濃度。一個是狀態、一個是流量的積分。弱相關是預期結果，不是量測缺陷，
更不代表其中之一不準。

這解釋了為什麼 `PMID:36523784` 中 PBR 與 thrombomodulin（內皮活化的功能性標記）
的相關性反而高於與 syndecan-1（結構脫落產物）——PBR 本來就更接近功能而非結構。

### 2.4 一個識別碼同時指向支持與反駁

`DOI:10.1186/s13054-018-1973-5` 是 ISICEM 增刊的**整卷** DOI。
支持本主張的 r = 0.40 摘要與反駁本主張的敗血症摘要**都在這一卷裡**，
各自沒有獨立識別碼。

因此該 DOI 既不能作為支持 token，也不能加 `!` 前綴作為反駁 token——
加哪一種都會誤導。本批的處理是 `evidence` 只收兩篇全文，增刊內容全部寫進 `note`。

〔推論〕這是 token 粒度的問題，與「相關但不對位」是不同的缺口：
那個是**文獻與主張的關係**無法表達，這個是**識別碼與文獻的對應**不是一對一。
會議增刊、學位論文、多篇合刊的補充材料都會有同樣情形。
目前只此一例，先記錄不提案。

## 3. 對 §3.3 通則的回測

本批沒有再次命中「逆向指標被寫反」。兩條 statement 對 PBR 方向的描述都正確：
`5.5` 寫「PBR 升高與 syndecan-1 升高呈正相關」——PBR 升高代表糖萼變薄，
syndecan-1 升高代表脫落增加，兩者同向是對的。

〔推論〕值得注意的是**原文在 §5 章談 PBR 時方向都寫對了，錯的是 §2.1.1**。
這與 §3.3 當初的觀察一致（「原文 2.1.2 自己寫對了」）。
方向錯誤集中在把 PBR 當**厚度數值**引用的地方，不在把 PBR 當**指標**討論的地方。

〔推論〕這給了一條可操作的篩選規則：PBR 出現在「≈ 某某 μm 的厚度」這種語境時高風險，
出現在「PBR 升高／降低」這種語境時低風險。前者才需要回頭核對方向。
