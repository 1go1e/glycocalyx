## 3. 淨新增 23 條的重點

### 數值型（4 條，全 `high`）

| claim_id | 數值 |
|---|---|
| `4.1-heparanase-hs-50-90pct-hours` | 動物實驗中 50-90% HS 於數小時內消失 |
| `4.2.1-dm-thickness-50-70pct` | 糖尿病患者厚度減少 50-70% |
| `4.2.1-dm-sdc1-shedding-3-10x` | 糖尿病患者 syndecan-1 脫落升高 3-10 倍 |
| （`2.3.2-glypican1-core-protein` 為列舉型） | |

**`50-90%` 這個數字在本批出現兩次而意義不同**，值得記一筆：

```
2.2-pathological-50-90pct          病理狀態下糖萼「厚度」減少 50-90%
4.1-heparanase-hs-50-90pct-hours   動物實驗中「HS 分子存量」50-90% 於數小時內消失
```

量不同（厚度 vs 分子存量）、條件不同（泛病理 vs 動物實驗加時間窗），
依 SCHEMA §2 建為不同條。若合併，就無法分辨兩者是同一個測量的兩種轉述，
還是兩個獨立測量碰巧同區間——而這正是本專案要偵測的東西。

`4.2.1-dm-thickness-50-70pct` 與 `2.2-pathological-50-90pct` 亦然：
範圍不同（50-70 vs 50-90）、族群不同（糖尿病 vs 泛病理）。
**此二列並存正是為了保留可偵測的漂移。**

### 合成側 vs 降解側（`4.2-endmt-synthesis-loss`）

v3 完全沒有 EndMT。本列的重要性在於它與既有的降解型機制**因果方向相反**：
MMP、heparanase、ROS 都是移除既有糖萼，EndMT 是使其**無法再生**。

〔推論〕帳本目前的損傷機制列幾乎全屬降解側。若合成側只有這一條，
`4.1` 與 `4.2` 的列數比會給人「糖萼損傷主要是被剪掉的」這個印象，
而那不一定是文獻的實情。後續批次遇到合成側機制時應特別留意。

### 治療類 3 條（`6.3`，全 `high`）

`6.3-sglt2-glp1-restore` 的原文措辭是「**已被證實**可部分恢復糖萼」，
屬未具名權威措辭，依 SCHEMA §6（v4）未納入 `statement`，記入 `note` 待查。

〔注意〕本檔 §2.5、§3.5、§4.5、§7 全段皆環繞 SGLT2i／GLP-1 RA 的糖萼保護作用。
**後續四批應追加 `source_ref` 而非另建列**，否則同一主張會出現五次。
已寫入該列 `note`。

`6.3-doxycycline-mmp-inhibitor` 的原文附「低劑量」，
依 `CLAUDE.md` 第 6 條，`statement` 不含劑量描述。

### 一條刻意未拆的複合宣稱

`5.5-triple-biomarker-elevation`：四個疾病族群 × 三個標記。
依 SCHEMA §6 本可拆為多條，但原文即以此複合形式呈現且未給任何一組的具體數值，
拆列會產生十二條同樣無數值的空列。查證時若發現各族群證據強度不同，再依 §6 拆。

## 4. 可能與既有列重複，待查證時確認

`4.1-ros-inhibits-gag-synthase`（ROS 抑制 EXT1 與 NDST1）與既有
`1.2-ext-activity-drop`（線粒體功能障礙或氧化壓力降低 EXT1/EXT2 活性）
**可能描述同一現象**：

| | 上游 | 標的 | 效果 |
|---|---|---|---|
| `1.2-ext-activity-drop` | 線粒體功能障礙／氧化壓力 | EXT1/EXT2 | 活性下降 |
| `4.1-ros-inhibits-gag-synthase` | ROS | EXT1、NDST1 | 抑制（表現或活性未明） |

差異在標的（是否含 NDST1）與效果層次（活性 vs 表現）。
本批未合併，理由是抽取階段不做語意判斷——那需要文獻才能定奪。
已在兩列的 `note` 互相標註，查證時一併處理，若證實為同一條依 SCHEMA §6 合併。

〔推論〕這是抽取階段特有的兩難：合併太早會抹掉差異，合併太晚會累積重複列。
本專案的既定立場是**寧可多列**（SCHEMA §2「一條主張，一列」的認定規則從嚴），
因為多列可以合併，合併過的列無法還原成兩條各自的出處。
