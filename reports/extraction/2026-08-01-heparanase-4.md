## 2. 三方並排：平行值在第三個樣本上的表現

§2 與 §3 兩兩對照時看到的是「數值不同」。加上 §4 這第三點之後，
可以分辨**範圍是往同一方向漂移，還是各自獨立偏移**。結論是後者——
沒有任何一組呈現單調趨勢。

### 2.1 heparanase 升高倍數

```
5.6.1-dkd-heparanase-10-50x        DKD 患者腎組織      10-50 倍   人體
5.6.2-dr-heparanase-20-100x        視網膜              20-100 倍  人體＋動物混寫
5.6.3-dn-sciatic-heparanase-30-80x 糖尿病鼠坐骨神經    30-80 倍   動物   ← 本批
```

三個範圍互相重疊，上下界各異，**族群限定各不相同**。
本批這一條因限於動物而 `claim_type=fact`，另兩條涉人體族群為 `epidemiology`——
依 schema v8 的硬性分界，後兩條不得以動物證據判 `verified`。

### 2.2 屏障貢獻百分比

```
5.6.1-dkd-charge-selectivity-70pct  腎小球     70%      僅電荷選擇性
5.6.2-dr-brb-barrier-60-80pct       視網膜     60-80%   電荷「與」機械
5.6.3-dn-bnb-barrier-70-80pct       血神經屏障 70-80%   未指明屏障類型   ← 本批
```

三條的**量綱界定逐節放寬**：電荷 → 電荷加機械 → 不指明。
數值卻沒有跟著擴大。這比單看任何一條都更可疑。

### 2.3 厚度減少幅度（第七個版本）

`5.6.3-dn-ccm-thickness-40-60pct`（角膜神經糖萼 40-60%）是七個版本中**最低**的一組，
且量測部位是角膜神經而非血管。前六個版本全部落在 50-90%（STATUS §3.15 的吸引子區間），
本條是第一個掉出該區間的——量測部位也是唯一非血管的。

### 2.4 「X 的本質就是糖萼病變」句式

```
5.6.1-dkd-microalbuminuria-is-glycocalyx  微量白蛋白尿   單一臨床表現
```

## 3. 模態遞增序列已確認

`STATUS.md` §3.20 在 §3 抽完時留了一個待驗證的推測：
文件對三個器官各寫一節，每節都要說明自己這個器官特別重要，
於是逐節出現「比前一節更嚴重」的措辭，而底下的數值並未跟著移動。

§4 證實了這一點，且不只出現在標題：

| 宣稱 | DKD | DR | DN |
|---|---|---|---|
| 可逆性 | 「最早的**可逆階段**」 | 「**可逆階段**的關鍵」 | 「早期干預可**完全逆轉**」 |
| 對糖萼的依賴 | —— | 「**幾乎完全**依賴」 | 「**完全**依賴」 |
| 節標題的比較 | 「比一般慢性發炎更嚴重」 | 「比腎臟更早、更劇烈」 | 「比腎臟、視網膜**更敏感**」 |

**而時間序的數值方向相反**：DKD 第一階段是「數天至數週」，DR 與 DN 都是「數週內」——
被宣稱最早的兩個器官，時窗反而比 DKD 晚或相同。

〔推論〕這一族的檢出成本很低（把三節的同位句並排即可），但**只有抽取階段做得到**。
回填時「可逆性」「依賴程度」「時間序」會落在三個不同的查證群。

〔推論〕本序列有一個實用的副產品：**模態最強的那一條通常最沒有出處**。
`5.6.3-dn-preclinical-fully-reversible`（可完全逆轉）是三條裡唯一的絕對宣稱，
而三條都沒有附任何逆轉實證。查證時建議從最強的那一條開始——
若它站不住，較弱的兩條也要一併收斂。

## 8. `measurement` 與 `epidemiology` 的分界：新的待決

schema v8 的硬性分界只寫在 `fact` vs `epidemiology` 之間：
主詞為人體族群且動物證據不足以判定者 → `epidemiology`。

但 **`measurement` 沒有這道約束**，而本批與前兩批共有五列是
「具名量測平台 + 人體患者」的組合：

```
5.6.1-dkd-sdf-sublingual-50pct         SDF，T2D 患者
5.6.1-dkd-em-early-thinning            電子顯微鏡，DKD 患者
5.6.2-dr-octa-thickness-50-80pct       OCT-A，DR 患者
5.6.3-dn-nerve-biopsy-albumin          神經活檢，糖尿病患者      ← 本批
5.6.3-dn-ccm-thickness-40-60pct        CCM，糖尿病患者          ← 本批
5.6.3-dn-em-microvascular-near-complete-loss  電子顯微鏡，糖尿病患者 ← 本批
```

依 v8 的字面，它們是 `measurement`（具名平台，驗證核心是該平台測到什麼），
本批依此填寫以維持與前兩批的可比性。但這六列都是人體宣稱，
而 `measurement` 同樣不帶「必須人體證據」的約束——
**同一個閘門在 `measurement` 這條路上仍然是開的**。

〔推論〕v8 修的是 `fact` 這條路，沒有修 `measurement` 這條。
成因是當時的樣本只有三列，看起來像個別分類問題；六列並排才看得出是同一個缺口。
這與本專案反覆遇到的型態一致：**要等第二批樣本才顯現**。

**待決**（見 `STATUS.md` §5）：是否把「人體族群」的判準提升為**跨型別的第一順位**——
先問「這條 statement 能不能用動物研究驗證」，不能就是 `epidemiology`，
之後才問是哪一種型別。若採行，上列六條全改 `epidemiology`，並遞增 schema v9。

本批不執行。
