## 2. 一篇文獻推翻四列：`DOI:10.1021/bi0356552`

Chen et al., *Biochemistry* 2004;43:4971-4977，
"Inflammatory Cytokines and Fatty Acids Regulate Endothelial Cell Heparanase Expression"。
**培養血管內皮細胞**，一篇之內同時給出四項與 §6.4 表衝突的結果：

| §6.4 表所稱 | 該文實測 |
|---|---|
| TNF-α／IL-1β 誘導 10-50 倍 | 培養液 heparanase 蛋白上升 **2-10 倍** |
| 經 **NF-κB** 途徑 | NF-κB 抑制劑**不影響** TNF-α 誘導的分泌 |
| 經 **MAPK** 途徑 | MAP kinase 與 JNK 抑制劑**皆不影響** |
| VEGF 誘導 5-10 倍 | VEGF 使 heparanase 分泌**減少** |

〔推論〕這一篇之所以在上一批沒出現，是因為上一批的檢索式都以**倍數**為軸
（`"heparanase" "10-50 fold"` 之類）。這篇的摘要寫的是 `2-10-fold`，字串不命中；
而它真正的價值不在倍數，在**四個抑制劑對照**。
要找到它，檢索式必須以「內皮細胞 ＋ 細胞激素 ＋ heparanase 表達調控」為軸，
而這個組合是在查**訊號途徑欄**時才自然形成的。

**倍數欄與途徑欄分兩批查，反而讓倍數欄的證據在第二批才到齊。**
這是本批最重要的程序發現，已寫入 `queries.md` §1.15。

## 3. 三種失效模式，都不是「查無此事」

### 3.1 把「參與」寫成「直接結合啟動子」

`4.1.3-hif1a-binds-hpa-promoter` 與 `4.1.3-estrogen-er-hpa-promoter` 同型。
兩列的原文都寫「X 結合 HPA 啟動子」，而文獻狀態分三級：

| 列 | 電腦預測位點 | 啟動子報導基因 | EMSA／ChIP |
|---|---|---|---|
| Egr1 | ✔ | ✔ | **✔** → `verified` |
| ER | ✔（四個推定 ERE） | ✔（MCF-7，ER 依賴） | **✘** → `partial` |
| HIF-1α | ✘ | ✘ | ✘ → `unsupported` |

〔推論〕**同一句型下藏著三種完全不同的證據狀態**，而原文的表格把三者寫成同一種東西。
判定的分水嶺是 EMSA／ChIP 這一項——沒有它，「結合」二字就沒有出處，
不論該轉錄因子確實參與調控的證據多強。

ER 這一列還撿到一個現成的方法學反例：`PMID:18949048` 檢驗 PCNA 基因附近兩個
演化保守的推定 ERE，報導基因無反應、ChIP 測不到 ERα 招募，結論是
ERE 的電腦預測必須經生化驗證。HPSE 這一列正處在該文警告的狀態。

### 3.2 細胞型別決定方向，而原文寫成無條件通則

本節點已有三例：

| 列 | 在腫瘤細胞 | 在血管內皮／黑色素瘤 |
|---|---|---|
| Egr1 → HPSE | 前列腺／乳腺／結腸癌：活化 | **黑色素瘤：抑制** |
| VEGF → HPSE | 黑色素瘤：誘導 | **內皮：減少分泌** |
| 細胞激素 → NF-κB → HPSE | 膠質瘤：成立 | **內皮：抑制劑無效** |

〔推論〕三例的共通點是：**支持方多為腫瘤細胞，反駁方是血管內皮。**
而本專案的脈絡是血管內皮糖萼。§6.4 那張表看似在談內皮，
實際引用的證據基礎主要來自腫瘤生物學——這是整張表的系統性歸屬問題，
不是七個獨立的小錯。已寫入 `STATUS.md` §3.24。

### 3.3 途徑被反寫（queries.md §1.13 的途徑欄版本）

`4.1.3-tnfa-il1b-mapk`：MAPK 在 heparanase 文獻中出現頻繁，但位置有二——
作為 heparanase 的**下游**（heparanase 過度表現 → p38 磷酸化上升、→ ERK → MMP-9），
或作為 Egr1 的上游（ERK1/2 → Egr1 → HPSE，但刺激是 PMA／ionomycin）。
**沒有一篇把 MAPK 放在「細胞激素 → heparanase」這條線的中間。**

上一批的 `4.1.3-vegf-5-10x` 是**倍數**被反寫，本列是**途徑**被反寫，成因結構相同。
`queries.md` §1.13 已擴充涵蓋途徑欄。

## 6. 一項與本批主題無關但必須記錄的發現

執行 SCHEMA §9 的驗收時，順手把該節「有明文格式而無對應檢查」點名的兩欄
（`claim_id` 的 §3 正規表示式、`evidence` 的 §4 token 形式）也各寫了一條檢查。

- `evidence` token 形式：全表 **0 違規**。
- `claim_id` 正規表示式：**7 列違規**，全部是既有列。

```
2.1.1-invivo-0.5-5um        2.1.2-pbr-cutoff-2.0-2.2    2.1.2-pbr-normal-1.8
2.1.2-pbr-screening-cutoff-2.0    2.1.2-pbr-treatment-target-2.0
2.2-brain-mouse-0.54-0.23   2.2-cap-0.2-0.5um
```

成因單一：slug 內嵌了含小數點的數值，而 §3 的正規表示式在 `-` 之後不允許 `.`。

〔注意〕這正是 STATUS §3.23（「規格寫了，檢查沒驗」）所預測的第二個實例，
而 SCHEMA §9 自己已經指名這兩欄「成因結構與本例相同，尚未出過事」。
**現在知道其中一欄已經出事了，而且早在 `2.1.x` 那批就出了。**

〔注意〕**不建議修正。** SCHEMA §3 規定 claim_id 永不改名，這七個 ID 已進入 repo 歷史。
可行的處置有三，需人工裁示，已列入 `STATUS.md` §5：
(a) 放寬 §3 的正規表示式允許 slug 內含 `.`；
(b) 維持規則，將這七列登記為永久豁免；
(c) 維持規則不加檢查，僅記錄。

## 7. 本批次有效的檢索詞

命中決定性文獻的四式：

```
EGR1 binds heparanase HPSE promoter EMSA chromatin immunoprecipitation functional sites
"Mutual enhancement between heparanase and vascular endothelial growth factor" melanoma Cancer Letters 2011 doi pubmed
Garsen heparanase angiotensin II glomerular endothelial cells induction mechanism proteinuria diabetic nephropathy signaling
"Inflammatory cytokines and fatty acids regulate endothelial cell heparanase expression" Biochemistry 2004 TNF
```

第三式的有效成分是**研究群人名**（Garsen／van der Vlag 的腎絲球 heparanase 系列），
與 `queries.md` §1.10 記錄的「早期實驗室人名比關鍵字更能定位原始量測」是同一招，
本批首次在**現役研究群**上用成功——上一批只用 `angiotensin II ... AT1 receptor PKC`，
拿到的是 ResearchGate 轉載頁，無識別碼而不得採計；改用人名一式即得 PubMed 原始摘要。

第四式是**先在他篇的參考文獻清單看到標題，再以完整標題加引號回查原文**。
這不違反 §1.6——清單只用來**取得檢索詞**，判定所依據的是回查後取得的期刊頁摘要本身。

失效的一式（記入 §4.2）：

```
TNF-alpha IL-1beta induce heparanase expression NF-kB dependent endothelial cells inhibitor blocks
```

回傳全是內皮黏附分子（VCAM-1、ICAM-1、IL-6、IL-8）的 NF-κB 文獻，無一涉及 heparanase。
`TNF-alpha + endothelial + NF-kB` 這個組合在內皮發炎文獻中訊噪比極低。
